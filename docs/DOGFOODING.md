# Fix log

What real use of Torqwave turns up, and what fixed it; the new work itself is in the [roadmap](../ROADMAP.md) and the [changelog](../CHANGELOG.md). It began as the dogfooding log of the 0.14.7 to 0.17.0 releases, and goes on as Torqwave becomes an editor and a DAW in one. This is the list: every problem found by using the app, in the order it was reported, with the version it was found in, what was wrong, the milestone that fixed it (see the [changelog](CHANGELOG.md)) and the release that carries the fix. Each has an [issue](https://github.com/BobClawblaw/torqwave/issues) as well, closed against the commit that fixed it; the numbers of those up to 0.15.10, from when the app was called SpectraBlade, are the old name's issues, not this repository's. A fix that is on main but not yet in a release (so in a build from the source, not in a downloaded disk image) reads "on main" until a release carries it. Problems still open stay at the top until a fix lands. New ones can be reported as issues or straight into this list.

1.0.0 is a round of use that adds nothing here.
