Torqwave Synth: Strings

17 of the 85 factory patches in Strings: the ones that use the most of the synth, the highest count first.

Each clip was rendered by Torqwave's own code (TorqwaveTests --sound-demos, in the repository) and written as an MP3. Nothing was added: no effects, no levelling, no editing, except that a clip still sounding where it stops is faded over its last 30 ms so the cut does not click. A point for each oscillator on, each of those with unison voices, each with a warp, the sub, the noise, each filter, each effect on, each modulation routing in use and each named macro. 1.9 MB in all; a clip loads only when you play it.
