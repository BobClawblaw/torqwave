# Torqwave

A free, open-source audio editor and DAW in one, for macOS, Windows and Linux. The latest release is 0.20.0.

- **[Download](https://github.com/BobClawblaw/torqwave/releases/latest):** the Mac disk image, the Windows installer and the Linux tarball.
- **[User guide](guide/):** how to do things, one job at a time. The app carries it too, under Help > User Guide.
- **[Sounds](sounds/):** hear Torqwave Synth and StringSwarm.
- **[How it compares](compare/):** a feature matrix against fifteen other editors and DAWs, updated with every release.
- **[Keyboard shortcuts](SHORTCUTS.html)**
- **[Source, changelog and issues](https://github.com/BobClawblaw/torqwave)**
