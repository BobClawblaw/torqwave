# Torqwave user guide

How to use Torqwave, one job at a time. The [README](../../README.md) lists everything the app does; this guide shows you how to do it.

Keys are written for the Mac. On Windows and Linux, read Ctrl for Cmd and Alt for Option, and Explorer (or your file manager) for Finder. Every key can be changed in Window > Keyboard Shortcuts..., and [SHORTCUTS.md](../SHORTCUTS.md) lists the ones Torqwave ships with.

## Pages

1. [Getting started](01-getting-started.md): installing, the first launch, the window, opening and saving.
2. [Editing audio](02-editing-audio.md): selecting, playing, cutting and pasting, fades, levels, markers, undo and saving.
3. [Spectral editing and repair](03-spectral-editing-and-repair.md): the spectrogram, selecting sounds by frequency, Heal, noise reduction and the repair effects.

More pages are on the way: effects and the rack, loudness and mastering, multitrack sessions, instruments and MIDI, recording, video and surround, the Sound Library, projects and file types, customising, and troubleshooting.
